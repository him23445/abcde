# BasePart

BasePart properties are available on parts such as `Part`, `MeshPart`, `SpawnLocation`, and `UnionOperation`.

### Properties

```luau
BasePart.CastShadow: boolean
```

Controls whether the part casts a shadow.

```luau
BasePart.CanCollide: boolean
```

Controls whether the part collides with other parts.

```luau
BasePart.Color: Color3
```

The part color.

```luau
BasePart.Locked: boolean
```

The locked state of the part.

```luau
BasePart.Massless: boolean
```

Controls whether the part contributes mass to its assembly.

```luau
BasePart.Reflectance: number
```

The reflectance of the part.

```luau
BasePart.Transparency: number
```

The transparency of the part from `0` to `1`.

```luau
BasePart.Position: Vector3
```

The world position of the part.

```luau
BasePart.AssemblyLinearVelocity: Vector3
```

The linear velocity of the part's assembly.

```luau
BasePart.Velocity: Vector3
```

An alias for `AssemblyLinearVelocity`.

```luau
BasePart.AssemblyAngularVelocity: Vector3
```

The angular velocity of the part's assembly.

```luau
BasePart.Size: Vector3
```

The size of the part.
