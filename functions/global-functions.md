# Global Functions

### identifyexecutor

```luau
identifyexecutor()
```

Returns two strings, being the executor's name and current version.

### base64encode

```luau
base64encode("string")
```

Encodes given string in base64.

### base64decode

```luau
base64decode("string")
```

Decodes given base64 string to normal string.
