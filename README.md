# Zyraph

Documentation for the Zyraph Luau environment.

Zyraph uses a standalone Luau VM rather than functioning as a traditional Roblox executor. It emulates selected Roblox classes, services, functions, and behavior without running scripts inside Roblox's Luau environment. This reduces direct interaction with Roblox's internal scripting runtime, although it does not guarantee that the application is undetectable.

If you are new to the Luau language, see [luau.org](https://luau.org/).
